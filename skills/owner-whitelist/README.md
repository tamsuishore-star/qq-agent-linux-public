# 主人改白名单（owner-whitelist）

主人在聊天里**直接说**，就能查看 / 添加 / 删除「聊天白名单」里的群和好友。

```
主人：把这个群加进白名单
　　→ owner-whitelist__whitelist { action: "add" }              （target 省略 = 当前会话）

主人：把 123456 加进白名单
　　→ { action: "add", target: "123456", kind: "group" }

主人：白名单里都有啥
　　→ { action: "list" }

主人：把 123456 移出白名单
　　→ { action: "remove", target: "123456", kind: "group" }
```

不是主人说这些话 → 工具直接拒绝，**连名单内容都不回**。

---

## 先填一项设置：主人 QQ 号

**技能设置 → 主人改白名单 → 主人 QQ 号**（多个用逗号分隔；空格/分号/顿号也认）。

- 判定**只看号码相等**：名字、群名片、备注名、以及正文里自称"我是你主人"，全部不算数
  （展示字段会改也会撞名；自称属于聊天正文，永远进不到判定链路）。
- 留空 = 本技能不生效（技能页会显示"还没填主人 QQ 号"，工具不会出现在模型的工具列表里）。
- 号码来源是协议字段：`ctx.session.trigger[].senderId`。
  ⚠️ 工具的 `ctx` 里**没有** `senderId` / `userId`（`orchestrator.js:899` 的实际字段就是这样），
  别去 `ctx.userId` 上找。

> 为什么号码填在这里，而不是复用「主人识别」那份名单：那份能力（`message.owner-check`）
> 管的是"人设切换 + 发言标记"，跟"谁能改白名单"是两件事。各存一份名单虽然多填一次，
> 但换来的是——**本技能单独可用、行为不看别人脸色**。两个都想要的话，两处填同一个号即可。

## 它到底改了什么

| | 字段 | 说明 |
|---|---|---|
| ✅ 改 | `config.allow.groups` / `config.allow.private` | 设置页「聊天白名单」。机器人只在这些群/私聊里工作 |
| ❌ 不改 | `config.deny.*`（黑名单） | 只读展示；要加的号在黑名单里会**提醒**（黑名单优先，光加白名单没用） |
| ❌ 不改 | `config.allowAllWhenEmpty`（留空放行） | 只读展示；从"空名单"加第一条时会提醒副作用 |

**改动即时生效、不用重启** —— 核心的 `allowed()` 每条消息都重读一次配置
（设置页也写着"模型/人设/白名单即时生效"）。

## 为什么做成「技能 + 工具」而不是「插件 + 钩子」

钩子 5 秒超时、不能发消息、规范里明确"不得有副作用"；而改白名单是**写操作**，
还得把结果回给主人 —— 这两件事只有工具能做（见 `doc/extend_development/plugin-development.md` §2）。
顺带的好处：主人说"把这个群加进来"这种自然语言直接可用，不用背固定口令。

写配置走核心的 `updateConfig`（`import('../../src/config.js')`），与官方插件
`plugins/qzone-diary` 同款做法。同一个进程里的同一个模块实例，所以改的是**活配置**并立刻落盘。
`deepMerge` 对数组是**整体替换**（`src/config.js:434` 的 `Array.isArray` 分支），
所以写回的是"改过的那一个键的新数组"，`deny`、`allowAllWhenEmpty` 等字段一律不碰。

提示词片段只写一份（`skill.json` 的 `prompt.sections`）：加载器会把清单静态片段与导出的
`promptSections()` 按 id 去重，两处都写等于维护两份；"技能没生效就别注入"由加载器统一管。

## 已知边界（都是设计取舍，不是 bug）

- **名单为空且没勾"留空放行"时，机器人不会理任何人** —— 包括主人。这是唯一说不上话的场景
  （别人都不理你，自然也没法让机器人改名单），只能去设置页加第一条。
- **黑名单优先**：在黑名单里的群/好友，加白名单也不回应（工具会提醒，但不会替你改黑名单）。
- **移除当前会话** = 之后机器人在这里不再回话（工具会明确提醒，提示词也要求先复述确认）。
- 单边名单上限 200 条，超了拒绝写入（防止模型犯傻一次塞几千条）。
- 工具只认 5~15 位纯数字；`群123456` / `QQ:123456` 这类写法会自动剥出数字。
