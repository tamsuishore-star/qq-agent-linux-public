# 发 QQ 空间（qzone-post）

把群友要求的内容发成一条 QQ 空间说说。**不需要浏览器、不需要鼠标、不需要外部程序** —— 直接走协议端原生接口 `send_qzone_msg`。

## 它怎么决定要不要加前缀

这是本技能最关键的一段逻辑，和你装的另一个插件联动：

| 「全局记忆互通」插件 | 发出去的正文 |
|---|---|
| **没装 / 没启用** | `【当前会话名】正文` |
| **已启用** | `正文`（不加前缀） |

前缀里的名字**永远是当前会话的名字**，不是发言人的名字：

- 群聊 → 群名（例如 `【大肥鱼群】今天很热闹`）
- 私聊 → 对方的昵称（例如 `【阿鲲】晚安`）
- 取不到名字时 → 退回群号 / QQ 号，并把这件事记进日志
- 未知会话类型 → 不加前缀（不猜）

判定是**运行时查询**，不是配置项：你随时把记忆插件关掉或打开，前缀行为立刻跟着变，不需要改本技能的任何设置。

判定的实现是双闸：既查插件是否启用（`isSkillActive`），也查它提供的共享记忆能力是否真的在（`hasCapability`）。任一为假就按"没互通"处理 —— 宁可多一个前缀，也不要丢归属。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 正文长度上限 | 1000 | 超了就拒绝并让模型压缩 |
| 说说可见范围 | 所有人可见 | 所有人 / 仅 QQ 好友 / 仅自己 |
| 允许带图片 | 关 | 开启后模型可以传图片地址 |
| 演练模式 | 关 | **只回正文不真发**，配置前缀规则时先用它试 |

> 建议第一次先开「演练模式」，在群里发一句"发个空间 测试一下"，看看模型拼出来的正文对不对，再关掉演练模式正式用。

## 工具

- `qzone-post__qzone_post` — 参数 `content`（正文）、`images`（可选图片地址数组）
- 模型触发时机：群友说「发个空间」「发条说说」「发空间」「投稿空间」「发个动态」

## 依赖与权限

- 依赖协议端的 `send_qzone_msg` 接口（snowluma 已支持）
- 不需要 `web_fetch`

## 失败时你会看到什么

| 现象 | 原因 |
|---|---|
| 模型完全不调用这个工具 | 技能被禁用了，或"发空间"被理解成别的意思 —— 看控制台「技能」页的可用性原因 |
| 报"发空间失败：协议端返回了错误" | 协议端拒绝了这次发表（登录态过期、内容过长等），详情在控制台日志 |
| 前缀不对 | 前缀跟的是**当前会话**：群里发就是群名，私聊发就是对方昵称。想不加前缀就启用「全局记忆互通」插件 |
| 报"连不上协议端" | 协议端没启动 |
