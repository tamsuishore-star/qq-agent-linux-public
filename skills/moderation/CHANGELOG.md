## v1.3.2（2026-10-21）

- 新增 before-tool 守门：机器人不是群管理员时，`mute_member` / `kick_member` / `recall_message` / `set_group_ban` / `set_group_kick` 直接拒绝调用，并提示别再尝试、别在聊天里摆管理员架子。
- 起因：实测在非管理员群仍会调禁言，被拒后才撤回自己的话，观感差。

# v1.3.1（2026-10-19）

## 修：机器人在「自己不是管理员」的群里仍摆管理员架子

- 现象（实测截图）：机器人在某个群不是管理员，却说「一分钟，自己冷静下」
  「哦，你也是管理」「那算了，惹不起」—— 没有禁言能力却装得像能动手。
- 根因：原实现只检查**目标**是不是群主/管理员，**从不检查自己**；
  而提示词与工具描述里写着「管理端已经授权你使用它」「不用先问、不用预告」，
  模型于是默认自己在所有群都有管理权限。
- 修法：
  1. `mute_member` / `kick_member` 动手前先查**自己**在群里的 role（owner/admin/member）；
     不是 admin/owner 时直接返回拒绝理由，并明确告知「别再在聊天里提禁言/踢人」。
  2. 新增 `before-llm-messages` 钩子，每轮给模型一句权限提示：
     「你不是所有群的管理员。禁言/踢人/撤回先调工具让工具告诉你行不行；工具说不行就别提这类话。」
  3. 查不到自身 role 时**不拦**（沿用原有哲学：让 QQ 服务端去拒绝）。
