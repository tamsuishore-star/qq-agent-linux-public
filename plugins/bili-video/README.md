# B站视频转发（bili-video）

群里有人发 B 站链接（含 `b23.tv` 短链）时，自动把**视频本体**下载下来转发进群，
并附标题 / UP 主 / 时长 / 原链接。

**不经过模型，零 token 消耗** —— 纯转发，机器人不会去"评论"视频内容。

## 依赖

系统里要有 **ffmpeg**（B 站视频通常是音视频分离的，需要合并）。

## 能力

- `media.download` —— 供其他模块复用的下载能力。

## 设置

| 项 | 默认 | 说明 |
|---|---|---|
| 清晰度（qn） | 16 | 16=360P、32=480P、64=720P。无 Cookie 时接口只保证 360P/480P |
| 体积上限（MB） | 100 | 超过就只发链接不下载（QQ 对视频体积有限制） |
| 下载超时（毫秒） | 60000 | 视频大或网络慢时可调大 |
| 视频落地目录 | 空 | 留空 = 应用 `data/bili-media`；发完即弃，超 2 小时自动清理 |
| 搜索结果排序 | up-first | `up-first`=UP 本人的优先；`up-only`=只发作者名对得上的；`play`=按播放量；`default`=接口原序。排序全在本地做，不消耗 token。**本插件自动转发链接时用不到排序**，该项与技能共用同一份配置 |
| 时长上限（秒） | 1800 | 高播放里混着大量循环歌单/助眠合集，不适合当「给别人听一首歌」。填 0 = 不限制 |
| 时长下限（秒） | 0 | 想避开十几秒的碎片片段可以设成 30 左右 |
| 关键词模糊补救 | 开 | 第一次搜索一条本人都没有时，用搜索建议把词补完整再搜一次。只在完全没搜到本人时触发 |

## 提示词片段

会往系统提示词注入一条说明，告诉机器人"群里的链接是插件自动转发的，你没看过内容，不要评论画面"。
